# AgroMarket — Módulo Catálogo de Productos

**Autor:** Mayra Buñay

AgroMarket es una plataforma web de comercialización de productos agrícolas que conecta productores del campo con consumidores urbanos.

El módulo Catálogo de Productos muestra el inventario de frutas, hortalizas y granos. Permite al comprador explorar, filtrar por categoría y ver detalle de cada producto.

## Funcionalidades
- Catálogo visual con tarjetas de producto
- Filtros por categoría: frutas, hortalizas y granos
- Página de detalle de producto

## Tecnologías
HTML5, CSS3, Git, Figma
